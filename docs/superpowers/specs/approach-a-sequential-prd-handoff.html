方案 A：线性 PRD 传递

Sprint 边界知识同步 · 最简落地

落地要求

  • • PRD 模板标准化（含 rule-id 字段）
  • • 知识库 Git repo + 分层目录已建立
  • • 各角色 AI prompt 注入知识库 context
  • • Sprint 回顾增加"规则提取"环节

优势

  • • 最易落地，改动最小
  • • 团队只需增加 PRD 引用意识
  • • 知识同步在 Sprint 边界，不干扰交付
  • • 适合刚开始建立 Harness 规范的团队

局限

  • • PRD 传递是线性的，反馈路径弱
  • • PRD 只读引用，不在循环中被更新
  • • 跨角色问题发现滞后
  • • 知识回流频率低（每 Sprint 一次）
