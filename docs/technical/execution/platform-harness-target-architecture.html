Platform Harness · 目标架构

Harness 是整个平台运行时；Agent 自主思考，领域模块守护事实，Delivery Control Process Manager 只计算确定性控制动作

单循环扩展为循环图

  • 每个 Work Cell 保留自主认知循环
  • 共享 Task / A2A / Gate 连接各节点
  • Harness 管节点生命周期与协作边

多状态机，不做万能状态

Task、A2A、Gate、Inbox、Invocation、Context、Effect、Delivery 各有唯一 owner。“完成”必须说明完成的是哪一层。

Agent 自主性的接缝

WorkContract 只给目标、验收、权限、上下文和预算；Agent 自己决定步骤，通过结构化 outcome 把控制权交回平台。

错误先归一化再恢复

profile 缺失、session 丢失、transport 降级、CLI error、context 缺失分别进入对应 owner，不能都当成“重试 Agent”。
