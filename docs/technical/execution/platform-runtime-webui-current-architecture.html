Agent Task Hub · Runtime 与 WebUI 当前架构

关键边界：人可以从 WebUI 发命令；WebUI 的自动事件消费者只能展示，不能替平台推进执行

人可以做什么

  • 在 WebUI 输入命令、点击操作、确认审批
  • Human Command Adapter 把意图送到正式 API
  • 服务端裁决后产生事实和事件，再投影回页面

WebUI 自动消费者不能做什么

  • 不能因 task.wakeup 自行启动 Agent
  • 不能因退出或错误自行重试、推进任务
  • 不能回传 A2A 执行 ACK 或写回领域状态

可靠性放在哪里

  • Inbox / Harness 拥有 Agent 启动与恢复
  • Dispatcher / Process Manager 拥有自动推进
  • Project room + 浏览器门禁共同保证项目隔离
