Agent Team · 结构化上下文控制面

语义、来源、生命周期、可见性、一致性与交付策略解耦；ContextManager 从字符串拼装器演进为 Context Compiler

核心变化

  • • Layer 不是事实模型，Artifact 才是
  • • 场景矩阵成为策略输入，不再包办注入
  • • revision/hash/watermark 驱动失效与增量
  • • ContextManager 演进为可观测 Compiler

效率来源

  • • 稳定前缀 bootstrap + on-change
  • • 工具与 Skill 按需发现，避免全量 schema
  • • 工作状态用快照替换，交互用游标增量
  • • 大正文留引用，运行时渐进读取

多 Agent 不变量

  • • 共享目标、决策、证据和 Artifact
  • • 私有对话、工具轨迹和思考默认隔离
  • • Handoff 带 causal parent 与 source revisions
  • • Task/possession 强一致，日志最终一致
