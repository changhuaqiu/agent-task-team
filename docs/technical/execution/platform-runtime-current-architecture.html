Agent Task Hub · Platform Runtime

一条主线：工作进入 Inbox → Agent 执行 → 形成平台事件 → 响应事件 → 完成终态后的可靠待办

怎么读这张图

  • 从左上角触发开始，沿实线进入 Inbox 和 ACP 执行层
  • 执行信号先变成 PlatformEvent，再由 Dispatcher 分发
  • Router 和 A2A Effect 可以产生下一轮 Inbox 工作

两层可靠执行

  • Dispatcher 重试 Event → Handler 的投递
  • Effect Outbox 重试 Agent 终态后的 Todo
  • 两者都用持久 attempt、lease 和有界重试

必须保持的边界

  • Runtime 终态不等于 Task 已完成
  • Effect Command 是执行意图，不是第五类事件
  • 当前没有实现 Agent 本身的 durable retry / checkpoint 恢复
