Agent Task Hub · 系统架构总览

多智能体协作平台 · Next.js 16 + React 19 + Zustand 5 + Socket.io + SQLite(drizzle) · CLI 优先（opencode/claude/codex）· 持球/传球 A2A 协作

核心数据流（一条主线）

  • ① 用户消息 → store.dispatchToAgent
  • ② PromptComposer 组装 16 层 prompt（预算裁剪）
  • ③ socket terminal:start → daemon
  • ④ DispatchGateway 建 ExecutionEnvelope + secret 检测
  • ⑤ Backend 执行：spawn 本地 CLI / HTTP bridge / tmux
  • ⑥ AgentEvent 流 → forwardAgentEvent
  • ⑦ 持久化(message/event/session/invocation) + Socket 广播
  • ⑧ A2A 扫描输出 → 持球/传球 → Task Flow 流转
  • ⑨ Wakeup 解除下游依赖 → 唤醒下一 Agent

关键缺口（按优先级）

  • P0 A2A → DispatchGateway 未集成（仍走 socket 兼容事件）
  • P0 types-v2.ts ↔ types-possession.ts 并行，迁移未完成（正在改）
  • P1 Runtime Router / Continue Gate / Possession Buffer 未实现
  • P1 ContextBudget 精度不足（字符÷4 估算，GSSC 未接入裁剪）
  • P2 gemini / mock 无独立 backend（回退 OpenCode）
  • P2 Tmux 模式是哑终端，不解析 AgentEvent
  • P2 MCP Server 端口/agent 列表硬编码
  • P3 backend/ 废弃目录未清理 · Bridge 无完整前端 UI
  • P3 Proof Log / Execution Envelope 消费端缺失
